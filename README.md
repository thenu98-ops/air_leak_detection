# Air Leak Detection

This repository contains the codebase for the Air Leak Detection project. It is structured as a monorepo containing the web application, hardware code, and related sources.

## Project Structure

- **`dashboard/`**: Contains the web dashboard application.
- **`arduino/`**: Contains the Arduino code for hardware interaction.
- **`sources/`**: Contains additional source files and documentation.

## Setup

See the individual directories for specific setup and execution instructions.
